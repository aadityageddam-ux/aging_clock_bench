# AgingClockBench Examples

This directory contains example Jupyter notebooks demonstrating how to use AgingClockBench.

## Getting Started

See the [Quick Start](../README.md#quick-start) section in the main README for a quick example.

## Contributing Examples

We welcome example notebooks! To add a new example:

1. Create a `.ipynb` file in this directory
2. Include markdown cells explaining what the example demonstrates
3. Use the bundled NHANES data (`load_nhanes_sample()`) or your own data
4. Make sure all cells run without errors
5. Submit a pull request to [aadityageddam-ux/aging_clock_bench](https://github.com/aadityageddam-ux/aging_clock_bench)
